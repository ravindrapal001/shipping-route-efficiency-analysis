# Business Reports

This folder contains the business insights and recommendations prepared for the Nassau Candy Distributor – Factory-to-Customer Shipping Route Analysis project.

## Reports

1. **Business Insights Report** – Highlights key findings from sales performance, factory distribution, geographic distribution, shipping modes, route performance and distance analysis.

2. **Business Recommendations Report** – Presents practical recommendations, suggested monitoring KPIs, implementation priorities and additional data requirements based on the analytical findings.

Both reports are provided as separate PDF documents for easy reference.
